\# Clasificación de Severidad de Dengue en Bucaramanga con Árbol de Decisiones



\## Proyecto

Asignatura \*Inteligencia Artificial Avanzada\* — Ingeniería de Software, Universidad Tecnológica del Oriente.



\## Descripción

Árbol de decisiones que clasifica la severidad clínica individual de casos de dengue en Bucaramanga (Sin signos de alarma / Con signos de alarma / Grave) a partir de síntomas iniciales y variables demográficas. A diferencia de la red neuronal (que predice incidencia semanal agregada), este modelo opera a nivel de paciente individual como herramienta de apoyo al triage clínico, priorizando la interpretabilidad de las decisiones.
